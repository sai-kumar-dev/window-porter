# Privacy Policy

Window Porter is designed to operate locally.

## Data collection

Window Porter does not collect, transmit, sell, rent, or remotely store browsing data or personal data.

## Network behavior

The extension contains no analytics, telemetry, advertising SDKs, cloud sync, remote scripts, or application network calls.

Restoring a saved URL causes the browser to navigate to that URL in the normal way.

## Local data

Window Porter may store these items locally inside extension storage:

- user preferences
- optional safety snapshots, only when enabled or manually created

Portable WPS/TXT/HTML files are downloaded to the user's normal downloads location.

## Sensitive URLs

A URL can itself contain private identifiers or temporary tokens. Exact export is the default because changing a URL can break restoration. An optional privacy-clean mode removes common analytics and token-like URL parameters.

## Page content and authentication

Window Porter does not request access to cookies, passwords, page DOM, website local/session storage, browsing-history API, or request interception.
