# Roadmap

## v0.3 — public beta

- Save/restore selection
- Search/filter/invert
- Inspector
- duplicate policies
- compatibility/reporting
- opt-in safety snapshots
- CI/spec/repo polish

## Stabilization toward v1.0

- broader real-browser fixture testing
- multi-monitor/window geometry edge cases
- Firefox container/tab-context investigation
- performance testing with hundreds/thousands of tabs
- localization/accessibility pass
- signed Firefox distribution and Chrome Web Store packaging
- Safari feasibility/adapter work

## Explicit non-goals for core

- cookie/password/login transfer
- covert enterprise-policy bypass
- telemetry/ads
- required cloud account
- AI features unrelated to session portability
