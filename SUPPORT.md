# Support

Window Porter is currently a public beta.

## Before opening an issue

Please capture:

- Window Porter version
- source browser and version
- target browser and version
- source/target operating system
- whether the problem affects export, import, selection, groups, duplicates, or safety snapshots
- the restore report/warning text, if available

## Privacy

Do **not** post private WPS files unchanged. URLs can contain account identifiers, private resource paths, invitation codes, or temporary tokens.

Before attaching a fixture:

1. replace private URLs with safe examples while preserving the structure needed to reproduce the bug, or
2. create a minimal reproduction using public URLs.

Never post cookies, passwords, auth tokens, browser profiles, or corporate/internal URLs.

## Security issues

Do not open a public issue for a vulnerability involving sensitive information. Follow the guidance in [SECURITY.md](SECURITY.md).
