# Window Porter v0.3.0 — Public Beta

This release turns Window Porter from a portable save/restore utility into an inspectable, selective recovery tool while preserving the local-only design.

Highlights:
- selective save and selective restore
- search/filter/invert controls
- imported-session inspection
- target compatibility summary
- duplicate policies
- restore reports
- opt-in local safety snapshots
- Chromium + Firefox Full + Firefox Legacy/ESR packages
- WPS v1 specification and repository contribution/CI scaffolding

WPS remains version 1. v0.3.0 does not add cloud sync, telemetry, cookie/login transfer, content scripts, or host permissions.
